# Documentation

Documentation of the **Dataspace Management UI**. The leading repository of the product is
[dataspace-mgm-service](https://github.com/eclipse-tractusx/dataspace-mgm-service) (TRG 2.04); it holds the architecture
documentation of the product, the admin guide and the interface documentation.

| Document | Content | TRG |
|---|---|---|
| [user](user/README.md) | End user manual: sign-in, company registration, review, administration | 1.07 |
| [architecture](architecture/README.md) | Architecture of the UI: layers, core packages, runtime configuration | 1.05 |
| [developers](developers/integrate-a-backend-module.md) | Hackathon guide: connect the UI to a backend module (example C3-M1) | 1.05 |
| [translations](developers/translations.md) | Texts as i18n keys in every language: namespaces, keys, adding a language | 1.05 |
| [Product architecture](https://github.com/eclipse-tractusx/dataspace-mgm-service/blob/main/docs/architecture/README.md) | arc42 documentation of the product | 1.05 |
| [Admin guide](https://github.com/eclipse-tractusx/dataspace-mgm-service/blob/main/docs/admin/README.md) | Installation and operation | 1.06 |
| [API](https://github.com/eclipse-tractusx/dataspace-mgm-service/blob/main/docs/api/README.md) | OpenAPI of the backend modules | 1.08 |
