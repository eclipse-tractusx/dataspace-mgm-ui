An OSP administrator explores a possible configuration overview. This is a discussion sketch, not an implemented management capability.

The screen, with its configurator

Data from the spec

  • C2-M5 defines OIDC discovery, JWKS and token endpoints; it does not define a portal configuration-management API.

Open questions

  • Frontend decision: no IAM configuration editor or live configuration screen in this iteration. The selected page is a mock-only specification reference; see apps/portal/src/features/access-control/C2-M5-DECISIONS.md.
  • C2-M5 README describes browser token exchange; the frontend architecture requires a BFF-managed session with no browser tokens. Reconcile the integration before implementation.

Decided 2026-11-06: layout=cards · detail=expanded · loading=skeleton. Illustrative reference only; no configuration API is specified.
